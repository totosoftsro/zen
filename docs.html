Instalace SDK

Zen nabízí oficiální knihovny pro nejpoužívanější jazyky:

# Node.js
npm install zen

# Python
pip install zen

# Ruby
gem install zen

# PHP
composer require zen/zen-php

# Go
go get github.com/zen/zen-go/v7

První platba

Pro vytvoření platby stačí pár řádků kódu. Následující příklad vytvoří Payment Intent na 2 499 Kč:

const zen = require('zen')('sk_test_...');

const payment = await zen.paymentIntents.create({
  amount: 249900, // v haléřích
  currency: 'czk',
  payment_method_types: ['card', 'apple_pay'],
  description: 'Objednávka #1052',
});

console.log(payment.client_secret);

Klient použije client_secret k dokončení platby pomocí Zen.js nebo mobilního SDK.

Webhooky

Webhooky umožňují Zenu informovat váš server o událostech asynchronně. Např. když je platba úspěšně zpracována.

// Express handler
app.post('/webhook', (req, res) => {
  const event = zen.webhooks.constructEvent(
    req.body, req.headers['zen-signature'], WEBHOOK_SECRET
  );

  if (event.type === 'payment_intent.succeeded') {
    console.log('Platba úspěšná:', event.data.object.id);
  }
  res.sendStatus(200);
});

Idempotence

Pro zabránění dvojí platbě používejte Idempotency-Key header. Opakovaný požadavek se stejným klíčem vrátí tentýž výsledek bez nového zpracování.

Rate limity

Zen API má následující limity:

  • Produkce: 100 požadavků za sekundu
  • Test: 25 požadavků za sekundu
  • Webhooks: Retry s exponenciálním backoff až 3 dny
⚠️ Pokud překročíte limit, obdržíte 429 Too Many Requests. Implementujte retry s backoff.
