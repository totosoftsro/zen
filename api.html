API Reference

REST API Zen funguje na bázi HTTPS a používá JSON. Base URL: https://api.zen.cz

Autentizace

Použijte Basic Auth s vaším API klíčem jako uživatelské jméno a prázdným heslem.

curl https://api.zen.cz/v1/customers \
  -u sk_live_51NxYz8...:

Payment Intents

Payment Intent představuje záměr přijmout platbu od zákazníka. Sleduje stavy a zajišťuje správné ověření.

Vlastnosti objektu:

NázevTypPopis
idstringUnikátní ID (pi_...)
amountintegerČástka v haléřích
currencystringISO kód měny (czk, eur, usd)
statusenumrequires_payment_method, requires_action, succeeded, ...
client_secretstringToken pro client-side potvrzení

Customers

Customer objekt reprezentuje zákazníka. Můžete k němu připojit platební metody a faktury.

Subscriptions

Předplatné automaticky fakturuje zákazníka v pravidelných intervalech.

Paginace

Seznamové endpointy podporují cursor-based paginaci pomocí parametrů limit, starting_after a ending_before.

Error handling

Zen používá konvenční HTTP status kódy. 2xx = úspěch, 4xx = chyba klienta, 5xx = chyba serveru.

Vytvoření platby
POST /v1/payment_intents

{
  "amount": 249900,
  "currency": "czk",
  "description": "Objednávka #1052",
  "payment_method_types": ["card"]
}

POST /v1/customers

{

  "name": "Jana Nováková",
  "phone": "+420777123456"
}
